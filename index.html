Инструкция по работе со смешанными числами

Основные понятия

Смешанное число

Число, состоящее из целой части и правильной дроби.

2½ = 2 + ½

Правильная дробь

Дробь, у которой числитель меньше знаменателя.

¾, ½, ⅔

Правила действий

  1. Сложение:

    Складываем целые части отдельно, дробные - отдельно.

    3½ + 2¾ = (3+2) + (½+¾) = 5 + 1¼ = 6¼
  2. Вычитание:

    Вычитаем целые части и дробные части отдельно.

    5¾ - 2½ = (5-2) + (¾-½) = 3 + ¼ = 3¼
  3. Приведение к общему знаменателю:

    Если у дробей разные знаменатели, приводим их к общему.

    ½ + ⅓ = ³/₆ + ²/₆ = ⁵/₆
